# LoveHate App 上线开发计划

> 技术方案：React Native | 登录：手机验证码 | 先上 Android | 预算 <100 元/月

## 当前进度

**已完成（Web MVP）**：用户注册/登录、情侣配对、记好/记仇、情绪温度计、复仇商店、道歉信/情书、冷战模式

**未完成**：情绪日历、周报/月报、成就徽章系统、推送通知、手机端适配

---

## Phase 2 — 后端生产化（1.5 周）

| # | 任务 | 天数 |
|---|------|------|
| 2.1 | SQLite → PostgreSQL（数据库迁移脚本 + Docker Compose） | 1天 |
| 2.2 | 短信验证码登录（阿里云短信/腾讯云 SMS，接入成本低） | 2天 |
| 2.3 | 文件上传（服务器本地存储，不花钱用 OSS） | 1天 |
| 2.4 | WebSocket 实时通知（对方在线状态、温度同步） | 2天 |
| 2.5 | 定时任务（记仇30天过期、温度自然衰减） | 1天 |
| 2.6 | 安全加固（Rate Limiting、Token 刷新、敏感词过滤） | 1天 |
