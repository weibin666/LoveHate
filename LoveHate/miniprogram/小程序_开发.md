# LoveHate 微信小程序开发总结

## 项目概况

基于现有 LoveHate 后端 API（FastAPI），完成微信小程序前端开发，复用全部 34 个 API 端点，采用 **Midnight Romance** 暗色主题。

---

## 项目结构 — 60 个文件

```
miniprogram/
├── app.js / app.json / app.wxss       # 全局配置、状态管理、主题样式
├── project.config.json / sitemap.json  # 项目配置
├── 小程序开发计划.md                     # 开发计划文档
├── assets/icons/ (10 个 PNG)           # TabBar 图标（常规态 + 选中态）
└── pages/ (11 个页面，每页 .js/.json/.wxml/.wxss)
    ├── login/           # 登录（密码 + 短信双模式，60s 倒计时）
    ├── couple/          # 情侣配对（创建空间 / 加入空间）
    ├── home/            # 首页（温度计 + 记好记仇 + 记录列表 + 冷战横幅 + 续期）
    ├── feed/            # 分享空间（发动态 + 心情标签 + 点赞 + 图片）
    ├── calendar/        # 情绪日历（月历网格 + 心情颜色 + 周报弹窗）
    ├── shop/            # 复仇商店（商店 / 我的券双 Tab + 自定义商品）
    ├── letters/         # 信箱（道歉信 / 情书 + 快速模板 + 接受拒绝）
    ├── profile/         # 个人中心（用户信息 + 情侣信息 + 成就入口 + 玩法说明）
    ├── achievements/    # 成就徽章（进度条 + 解锁 / 未解锁网格）
    ├── record-detail/   # 记录详情（续期 30 天 + 删除）
    └── letter-write/    # 写信（类型切换 + 快速模板）
```

## 页面与功能对照

| TabBar 页面 | 功能 | 调用 API |
|------------|------|---------|
| **首页** home | 温度计动画、记好/记仇表单（情绪选择+图片+文字）、记录列表（续期按钮）、冷战横幅（和好按钮）、实时通知横幅 | POST /records, GET /records, GET /records/stats, POST /records/{id}/renew, POST /game/coldwar/reconcile, POST /upload/image |
| **空间** feed | 动态列表（头像、昵称、相对时间、心情标签）、发动态（6 种心情+图片）、点赞/取消、删除 | GET /posts, POST /posts, POST /posts/{id}/like, DELETE /posts/{id} |
| **日历** calendar | 月历网格（颜色编码：绿=好 紫=仇 黄=中性）、月份切换、周报弹窗（统计+评语） | GET /calendar/monthly, GET /calendar/weekly-report |
| **信箱** letters | 信件列表（道歉=紫色边框、情书=粉色边框）、接受/拒绝按钮、写信弹窗（类型+模板） | GET /game/letters, POST /game/letter, POST /game/letter/{id}/accept |
| **我的** profile | 头像昵称、爱情币、情侣信息（状态/邀请码/温度/另一半）、成就入口、6 条玩法说明、退出登录 | 无直接 API（读取 globalData） |

| 非 TabBar 页面 | 功能 | 调用 API |
|---------------|------|---------|
| **登录** login | 密码登录/注册 + 短信验证码登录，模式切换 | POST /auth/login, POST /auth/register, POST /auth/sms/send, POST /auth/sms/login, GET /auth/me |
| **配对** couple | 创建空间（生成邀请码）/ 加入空间 | POST /couple/create, POST /couple/pair |
| **商店** shop | 商店/我的券双 Tab、购买确认、自定义商品 | GET /game/shop, POST /game/shop/{id}/buy, GET /game/purchases, POST /game/shop |
| **成就** achievements | 进度条（已解锁/总数）、解锁（金色光效）/ 未解锁网格 | GET /achievements |
| **记录详情** record-detail | 记录内容、图片、续期按钮、删除 | POST /records/{id}/renew, DELETE /records/{id} |
| **写信** letter-write | 道歉信/情书切换、3 个快速模板 | POST /game/letter |

## 技术架构

### 全局状态管理
- `app.globalData` 存储 user / couple / token
- `wx.setStorageSync('lovehate_token')` 持久化 Token
- `app.doLogout()` 统一登出逻辑

### 网络请求封装
- `app.request({ url, method, data })` 基于 `wx.request`
- 自动附加 Bearer Token
- **401 自动刷新**：调用 `POST /auth/refresh`，刷新成功后重试原请求
- `app.uploadFile(filePath)` 封装 `wx.uploadFile`

### 文件上传
- `wx.chooseMedia` 选择图片
- `wx.uploadFile` 上传到后端 `/api/upload/image`

### WebSocket（预留接口）
- `app.globalData.wsConnected` / `lastMessage` 状态位
- 可对接 `wss://域名/ws/notify?token=` 实现实时通知

### 色彩体系

| Token | 色值 | 用途 |
|-------|------|------|
| `--love` | `#ff4d6d` | 主色调（爱/粉红） |
| `--love-light` | `#ff8fa3` | 浅粉 |
| `--hate` | `#845ec2` | 次色调（恨/紫色） |
| `--hate-light` | `#b08cdb` | 浅紫 |
| `--gold` | `#ffd700` | 爱情币/成就 |
| `--ice` | `#a2d2ff` | 冷战/冰冻 |
| `--bg` | `#0a0a14` | 主背景（极深蓝黑） |
| `--surface` | `#161628` | 卡片背景 |
| `--surface-light` | `#1e1e36` | 输入框背景 |
| `--text` | `#f0f0f5` | 主文字 |
| `--text-secondary` | `#9ca3af` | 次要文字 |
| `--text-muted` | `#6b7280` | 弱化文字 |
| `--success` | `#4ade80` | 成功/记好 |
| `--error` | `#f87171` | 错误/警告 |

- 品牌：`love → hate`（hero 区域）
- 冷战：`rgba(59,130,246,0.2) → rgba(99,102,241,0.1)`

## API 调用清单（34 个端点全部复用）

### 认证 (6)
- `POST /api/auth/register` — 注册
- `POST /api/auth/login` — 密码登录
- `POST /api/auth/sms/send` — 发送验证码
- `POST /api/auth/sms/login` — 短信登录
- `POST /api/auth/refresh` — 刷新 Token
- `GET /api/auth/me` — 获取用户信息

### 情侣 (3)
- `POST /api/couple/create` — 创建空间
- `POST /api/couple/pair` — 加入空间
- `GET /api/couple/info` — 获取情侣信息

### 记录 (5)
- `POST /api/records` — 创建记录
- `GET /api/records` — 记录列表
- `GET /api/records/stats` — 记录统计
- `DELETE /api/records/{id}` — 删除记录
- `POST /api/records/{id}/renew` — 续期记仇

### 游戏 (8)
- `GET /api/game/shop` — 商品列表
- `POST /api/game/shop` — 创建自定义商品
- `POST /api/game/shop/{id}/buy` — 购买
- `GET /api/game/purchases` — 我的券
- `POST /api/game/coldwar/reconcile` — 和好
- `POST /api/game/letter` — 发信
- `GET /api/game/letters` — 信件列表
- `POST /api/game/letter/{id}/accept` — 接受/拒绝

### 日历 (3)
- `GET /api/calendar/monthly` — 月历数据
- `GET /api/calendar/weekly-report` — 周报
- `GET /api/calendar/daily/{date}` — 每日记录

### 动态 (4)
- `POST /api/posts` — 发动态
- `GET /api/posts` — 动态列表
- `POST /api/posts/{id}/like` — 点赞
- `DELETE /api/posts/{id}` — 删除

### 成就 (1)
- `GET /api/achievements` — 成就列表

### 上传 (2)
- `POST /api/upload/image` — 上传图片
- `POST /api/upload/avatar` — 上传头像

### WebSocket (1)
- `WS /ws/notify?token=` — 实时通知
