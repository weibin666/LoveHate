# LoveHate 微信小程序开发计划

> 基于现有后端 API（FastAPI），开发微信小程序前端，复用全部 34 个 API 端点

---

## 项目概述

将现有 React Native 移动端功能完整迁移到微信小程序平台。后端 API 完全复用，仅开发小程序前端。

### 技术选型

| 项目 | 方案 |
|------|------|
| 框架 | 原生微信小程序 + TypeScript |
| 状态管理 | 全局 App 实例 + 自定义 Store |
| 网络请求 | wx.request 封装（含 Token 自动刷新） |
| 实时通信 | wx.connectSocket（WebSocket） |
| UI 风格 | Midnight Romance 暗色主题（与移动端一致） |

### 与 RN 版本对应关系

| RN 依赖 | 小程序替代 |
|---------|-----------|
| axios | wx.request 封装 |
| zustand + AsyncStorage | globalData + wx.setStorageSync |
| expo-linear-gradient | CSS linear-gradient |
| expo-image-picker | wx.chooseMedia |
| react-native-reanimated | wx.createAnimation + CSS transition |
| @react-navigation | 原生 tabBar + wx.navigateTo |
| SafeAreaView | 页面自适应 |

## API 调用清单（34 个端点全部复用）

### 认证 (6)
- `POST /api/auth/register` - 注册
- `POST /api/auth/login` - 密码登录
- `POST /api/auth/sms/send` - 发送验证码
- `POST /api/auth/sms/login` - 短信登录
- `POST /api/auth/refresh` - 刷新 Token
- `GET /api/auth/me` - 获取用户信息

### 情侣 (3)
- `POST /api/couple/create` - 创建空间
- `POST /api/couple/pair` - 加入空间
- `GET /api/couple/info` - 获取情侣信息

### 记录 (5)
- `POST /api/records` - 创建记录
- `GET /api/records` - 记录列表
- `GET /api/records/stats` - 记录统计
- `DELETE /api/records/{id}` - 删除记录
- `POST /api/records/{id}/renew` - 续期记仇

### 游戏 (8)
- `GET /api/game/shop` - 商品列表
- `POST /api/game/shop` - 创建自定义商品
- `POST /api/game/shop/{id}/buy` - 购买
- `GET /api/game/purchases` - 我的券
- `POST /api/game/coldwar/reconcile` - 和好
- `POST /api/game/letter` - 发信
- `GET /api/game/letters` - 信件列表
- `POST /api/game/letter/{id}/accept` - 接受/拒绝

### 日历 (3)
- `GET /api/calendar/monthly` - 月历数据
- `GET /api/calendar/weekly-report` - 周报
- `GET /api/calendar/daily/{date}` - 每日记录

### 动态 (4)
- `POST /api/posts` - 发动态
- `GET /api/posts` - 动态列表
- `POST /api/posts/{id}/like` - 点赞
- `DELETE /api/posts/{id}` - 删除

### 成就 (1)
- `GET /api/achievements` - 成就列表

### 上传 (2)
- `POST /api/upload/image` - 上传图片
- `POST /api/upload/avatar` - 上传头像

### WebSocket (1)
- `WS /ws/notify?token=` - 实时通知
